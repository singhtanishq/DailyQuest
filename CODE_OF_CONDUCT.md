# Code of Conduct

## Our standard

Everyone participating in this project — issues, pull requests, discussions — is expected
to be professional and constructive. Specifically:

- Be technical, precise, and kind. Critique code and content, not people.
- Assume good faith; ask before assuming bad intent.
- No harassment, discrimination, trolling, or personal attacks.
- No spam, advertising, or links to malicious content.

## Scope

This applies to the project's repository spaces (issues, PRs, discussions) and to any
project-related communication.

## Enforcement

Violations can be reported privately via
[GitHub security advisory](https://github.com/singhtanishq/DailyQuest/security/advisories/new)
or by contacting the maintainer directly. The maintainer may edit, lock, or remove
content and may temporarily or permanently restrict participation. Decisions can be
appealed once, in writing.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
